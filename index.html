Installation & Setup Guide

Step 1: Download & Extract
Download the appropriate extension ZIP above. Extract the archive into a dedicated folder on your local machine.
Step 2: Chrome Developer Mode
Open Google Chrome and navigate to chrome://extensions. In the top right corner, toggle Developer mode to ON.
Step 3: Load Unpacked
Click Load unpacked in the top left and select the extracted extension directory (e.g. dce-agent-extension).
Step 4: Site Permissions (Mic)
On the DEL CRM portal, click the Padlock / Tune icon in the address bar. Set Microphone to Allow, then reload the page.
